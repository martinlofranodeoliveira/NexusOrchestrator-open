# Validador opcional

A integração com OpenCode exige instalação e autenticação próprias do usuário. Nenhuma conta, chave, assinatura ou configuração operacional acompanha esta edição. Validadores externos ficam desativados no template; habilite somente por escolha explícita na própria pasta de trabalho. Testes usam mocks e não devem chamar serviços reais.
